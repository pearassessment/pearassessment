# Pear Assessment

Free student tutorials for Pear Deck & Edulastic — join codes, student-paced mode, assignments & scores, explained step by step.

**Website:** https://pearassessment.org/

## What Pear Assessment publishes

Step-by-step guides written for students: how to join a Pear Deck session with a join code at joinpd.com, how student-paced mode works, how to answer interactive questions, how to complete Edulastic assignments, and how to check scores and feedback. Every guide is free and needs no signup.
